# ランダムダンジョン部屋・エンカウンター ダイスロール TRPG補助

TRPGセッション用のダンジョン部屋ランダム生成とダイスロール補助ツール。

## 機能

- 部屋タイプ（通路/部屋/宝物庫/罠部屋/神殿/ボス部屋）・サイズ・出口方向・エンカウントをワンクリックで生成
- d4/d6/d8/d10/d12/d20/d100の個別ロールと複数ダイス同時ロール対応
- エンカウント表（d20）・モンスター難易度表（d8）・宝物表（d6）の自動参照とGM描写文生成
- ロール履歴最大50件表示（時刻・ダイス種・全出目・合計）
- 部屋メモ機能（localStorageに最大20件自動保存）
